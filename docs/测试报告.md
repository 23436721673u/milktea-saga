## 3. 事务回滚验证（T15）

启动参数加 `-Dmilktea.rollbackDemo=true`，程序会在写入订单主表和明细后、扣库存之前抛出异常。

下单前：

```
orders=7 items=12 stock1=18 wang=319
```

下单输出：

```
确认下单？(y/n) > y
✗ 下单失败，已回滚：【回滚演示】主表和明细已写入，人为制造失败
```

下单后：

```
orders=7 items=12 stock1=18 wang=319
```

订单数、明细数、珍珠奶茶库存、王同学积分完全不变，说明已写入的主表和明细随事务一起回滚。

## 4. 测试中发现并修复的问题

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 订单 #1 插入时间为 14:30，界面显示 06:30 | 用 `rs.getTimestamp()` 读取 DATETIME 时，驱动按 `serverTimezone` 与 JVM 时区做了换算；JVM 与数据库时区不一致时出现偏移 | 改为 `rs.getObject("created_at", LocalDateTime.class)`，按库中原值读取，修复后显示 `2026-11-01 14:30:00` |
